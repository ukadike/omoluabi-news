# Archive

Retired components, preserved intact.

Nothing in this project is deleted when it is superseded. A retired component
moves here whole — code, history, and honest labeling — so its provenance
stays checkable. Each archived component carries an `ARCHIVED.md` stating what
it was, when and why it was retired, and what replaced it.

## Contents

- `engine-browser-prototype/` — the first running web engine (browser-only
  human review interface over the governance pipeline). Retired 2026-08-16.
  See its `ARCHIVED.md`.

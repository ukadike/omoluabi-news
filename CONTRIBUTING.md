# Contributing

Omoluabi News is in active pre-public testing (Omoluabi MVP v1). Broader
external contribution is planned but not yet open — see this
repository's `README.md`, "Contributing" section, for current status.

For the actual mechanics of adding a story, a source, or a reasoning
layer, or using the research-ingestion tools, see
[`docs/CONTRIBUTING.md`](docs/CONTRIBUTING.md) — that file is the
canonical, detailed guide; this one exists at the root only because
that's where contribution guidelines are conventionally expected to be
found.

Before contributing, also read:

- [`docs/EDITING-GUIDELINES.md`](docs/EDITING-GUIDELINES.md) — no
  fabrication, sourcing requirements, example vs. published content.
- [`docs/ETHICAL_SCRAPING_POLICY.md`](docs/ETHICAL_SCRAPING_POLICY.md) —
  required before registering or using a real research source.
- [`docs/ACCESSIBILITY.md`](docs/ACCESSIBILITY.md) — required patterns
  for any new page or component.
